# Аудит 3D-моделей

Соблюдай корневой `AGENTS.md`, не перечитывая его, если он уже в контексте. Пути ниже — от корня проекта. Blender MCP нужен для измерений/осмотра, существующие скрипты — для воспроизводимого сравнения; запускай только проверки из объёма аудита.

## Подготовка

1. Определи файл, вариант сжатия, манифест и ожидаемые структуры. Зафиксируй путь, размер и SHA-256 оригинала.
2. Проверь доступность Blender MCP и состояние Blender. Не очищай пользовательскую сцену; импортируй рабочую копию в отдельную сцену/коллекцию, сохраняя существующие объекты и файл.
3. Оригинальные GLB, base64-копии и резервные модели не изменяй без явного разрешения. Аудит не разрешает apply transforms, merge, remesh, decimate, переименование, исправление нормалей или перезапись экспорта.
4. Если Blender не читает meshopt-сжатый GLB, используй имеющийся резервный `*-q-glb.txt` или исходную модель. Укажи, какой вариант осмотрен; опубликованный файл отдельно проверяется GLTFLoader. Не устанавливай дополнения автоматически.

## Измерения через Blender MCP

- По сцене и объектам посчитай mesh-объекты, уникальные mesh datablock, вершины, полигоны и треугольники. Используй loop triangles без изменения топологии; разделяй уникальную геометрию и экземпляры.
- При модификаторах разделяй исходную и evaluated-геометрию. Разницу методов подсчёта не выдавай за потерю данных.
- Проверь bounding box в мировых координатах, единицы, object scale, отрицательный determinant и неравномерный масштаб. Сравнивай с манифестом/исходником, а не с предполагаемыми размерами человека.
- Учитывай преобразование BodyParts3D → Three.js из AGENTS.md и Y-up glTF → Z-up Blender при импорте. Не применяй преобразование повторно и не определяй сторону только по локальному X Blender.
- Ищи вырожденные грани, нулевые площади, разрывы, non-manifold рёбра, изолированные компоненты, несогласованные нормали и самопересечения. Укажи метод/допуск; непроверенное свойство не объявляй исправным.
- Различай точные дубликаты и допустимые экземпляры, симметричные кости или региональные копии мышц. Совпадающий bounding box не доказывает дублирование.
- Сверяй названия и иерархию с `scripts/manifest*.py`: `m|мышца|часть`, `b|кость`, `o|структура`, `c|id`. Учитывай имена на родителях после gltfpack и несколько компонентов одной кости.

## Совместимость и проверки

- Через Playwright MCP проверь опубликованный GLB в Three.js 0.170.0/GLTFLoader с имеющимся MeshoptDecoder: загрузку, материалы, иерархию и сопоставление с карточками. Успешный импорт Blender не заменяет эту проверку.
- Для головы доступны `tools/export-head-geometry-check.mjs` и `verify/verify_head_geometry.py`; для контекста — `tools/verify-context-bone-models.mjs`, для регионов — соответствующие `verify-*-data.mjs`. Перед запуском прочитай входы/выходы, исключи перезапись моделей.
- После аудита сравни SHA-256 оригинала. При недоступности MCP сообщи об ограничении; проверки метаданных не выдавай за осмотр Blender.

## Результат

Укажи файл/хеш и инструменты; представь метрики и дефекты с объектом, методом, серьёзностью и рекомендуемым действием. Отделяй дефект от естественного анатомического отверстия и ограничения сегментации. Исправления предлагай отдельно; исправность сетки не доказывает анатомическую полноту.
