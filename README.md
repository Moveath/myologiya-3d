# Миология 3D — учебный 3D-атлас анатомии

Интерактивный 3D-атлас мышц и костей на русском языке с латинскими названиями. Делается для студента-медика, который хочет стать хирургом, поэтому главное требование — **анатомическая точность**: новые утверждения должны быть проверены по источникам, латынь и список образований костей — по международной анатомической терминологии (Terminologia Anatomica, TA98). Текущие ограничения раздела головы перечислены ниже.

Публичный сайт: **https://myologiya-3d-egor.nifty-spool-0531.chatgpt.site/**

Копия на GitHub Pages: https://moveath.github.io/myologiya-3d/

Исходники: https://github.com/Moveath/myologiya-3d

На Windows можно запустить файл **«Открыть атлас.cmd»** (нужен Python 3).

Локально: `cd site && python3 -m http.server 8000`, затем открыть http://localhost:8000/local.html (нужен интернет: three.js и шрифты грузятся с CDN).

## Задание (что это за проект и что нужно делать)

Сделать бесплатный учебный атлас, похожий по возможностям на приложение «Anatomy 3D Atlas» (Catfish Animation Studio), но **своими силами и только из открытых данных**: ничего не копировать из платных приложений (ни моделей, ни текстов), приложение — только ориентир по функциям.

Что должно быть у атласа:
1. Разделы тела (голова, шея, туловище, верхняя конечность, таз и нижняя конечность) и подразделы внутри них — так, чтобы разобрался даже человек без медицинского образования.
2. 3D-модель, которую можно крутить и приближать; нажатие на мышцу или кость открывает карточку.
3. Мышцы — с отдельными частями и головками (у дельтовидной 3 части, у двуглавой 2 головки и т. д.). Карточка мышцы: начало, прикрепление, функция, иннервация, кровоснабжение, примечания.
4. Кости — с точками-ориентирами. **На каждой кости ровно столько точек, сколько терминов в официальном списке TA98 для этой кости** — без пропусков и без лишних. У каждой точки: русское название, латынь, код TA98, понятное описание, какие мышцы здесь начинаются/прикрепляются. Непостоянные образования помечены по анатомическим источникам; скобки TA98 сами по себе не доказывают непостоянство. Места прикрепления мышц, у которых нет своего термина, показываются отдельно и в счёт не входят.
5. Режим теста, поиск по списку (по-русски и по-латыни), словарик терминов, слои (снятие мышц по глубине), светлая и тёмная тема, нормальная работа на телефоне.
6. Правила точности:
   - данные по мышцам сверять минимум с двумя независимыми источниками; где русские и англоязычные учебники расходятся — писать об этом прямо в карточке, а не выбирать молча;
   - латынь — по TA98; русские термины — по русскому изданию «Международная анатомическая терминология» (под ред. Л. Л. Колесникова, 2003), старые учебные названия — в скобках/описании;
   - список TA98 по костям проверяется скриптом (см. AGENTS.md), а не вручную;
   - честно помечать, где на модели чего-то нет (например, непостоянные косточки) или где точка условно ставится на линию/поверхность.

## Что делать дальше (бэклог, по приоритету)

1. **Завершить мелкую геометрию основного черепа.** Все 521 записи TA98 имеют маркеры и топографические описания по двум независимым источникам. Дополнительные просмотры Z-Anatomy и микро-КТ позволяют изучать другую геометрию, но не заменяют проверку каждого образования на основной модели. Следующий шаг — заменить оставшиеся проекции проверенной геометрией отверстий, каналов, борозд и остей, с отдельной регистрацией и повторной расстановкой точек. Наличие анатомических вариантов проверять отдельно.
2. **Раздел «Мочеполовая система».** В BodyParts3D есть почки, мочевой пузырь, мочеиспускательный канал и мужские половые органы (яички, придатки, семенные пузырьки, предстательная железа, половой член). Женских органов в этих данных нет — нужно найти открытые модели с совместимой лицензией. Термины и описания — по главам «Мочевая система» и «Половые системы» TA98.
3. **Продолжение головы, шея и туловище** — слуховые косточки, мышцы глазного яблока, языка и глотки, затем новые области по тем же правилам.
4. **Пометка «для экзамена»** — если будет список кафедры, отметить нужные точки/мышцы и добавить фильтр.
5. **Тест по точкам на костях** (показывается точка — выбрать название).
6. Суставы и связки, затем сосуды и нервы.

## Голова: объём и ограничения

Добавлены обе стороны восьми парных и шесть непарных костей черепа, мимические и жевательные мышцы. Стиль, слои, поиск на русском и латыни, карточки, выделение частей и тест сохранены. Для головы есть шесть стандартных ракурсов. Зубы показаны как контекст, без отдельных карточек; слуховые косточки в эту сборку не включены.

В голове по умолчанию включён режим **«Цвета костей»**. Каждому типу кости назначен постоянный учебный цвет; правая и левая одноимённые кости окрашены одинаково. Это условная раскраска для запоминания. Переключатель возвращает обычный цвет костной ткани, а «Легенда» показывает названия и позволяет выбрать кость. Настройка сохраняется в браузере; на время теста раскраска отключается. Чтобы видеть весь цветной череп, нужно выбрать слой «Кости».

Номенклатурная полнота и геометрия проверяются отдельно. В каталоге каждой кости ровно её список TA98. **Все 521 записи имеют 3D-маркеры и описания с двумя независимыми анатомическими источниками.** Тип локализации виден в карточке:

- **313 маркеров на поверхности** — выбран участок видимого образования, поверхности или края отверстия. Один маркер не изображает всю его протяжённость.
- **194 анатомические проекции** — источники подтверждают положение образования, но его мелкий рельеф или просвет нельзя достоверно различить на сетке BodyParts3D. Маркер показывает ожидаемую область, а не доказывает наличие отверстия, борозды или канала в геометрии.
- **14 мест вариантов** — показана типичная область непостоянного образования; его наличие у человека, по которому создана модель, не установлено.

Таким образом, охват маркерами полный, а точная геометрия мелких образований остаётся ограничением модели. Внутрикостные каналы не реконструированы из одиночной точки; расхождения анатомических источников сохранены в примечаниях. Парные кости проверены по отдельным сеткам обеих сторон.

Кнопка **«Подробная модель»** открывает отдельную страницу `site/skull-detail.html` с двумя источниками:

- **«Кости и пазухи» — Z-Anatomy, CC BY-SA 4.0.** В модели 22 отдельные кости и 8 объектов воздушных полостей: лобная и клиновидная пазухи, передние, средние и задние решётчатые ячейки с обеих сторон. Цветные формы пазух показывают воздушное пространство, а не кость или ткань. Есть выбор, скрытие и изоляция структур, прозрачность и срез. Выполнены исходные авторские операции вычитания ячеек решётчатой кости; новые отверстия по догадке не создавались. Геометрия остаётся учебной и упрощённой, с открытыми краями и небольшими артефактами сетки. Полные мелкие каналы не заявлены.
- **«Микро-КТ» — отдельный препарат Halle, CC BY 4.0.** Поверхность построена из опубликованной сегментации костной ткани. У образца отсутствует нижняя челюсть, имеется подготовительный распил и описанный автором небольшой трепанационный дефект правой теменной кости. Их нельзя принимать за обычные анатомические отверстия. Кости в исходной бинарной маске не разделены. Исходный шаг вокселя — **0,125 мм**, шаг выборки для браузерной поверхности — **0,25 мм**, затем сетка дополнительно упрощена. Эти числа обозначают этапы обработки и **не являются гарантией точности**; самые мелкие детали могут быть утрачены. Срез в просмотрщике отсекает поверхность 3D-сетки, а не показывает плотности томографического изображения.

У обеих дополнительных моделей собственные координаты. Они не совмещены с BodyParts3D, и точки основного атласа на них не перенесены. **Основной череп по-прежнему имеет 521 маркер: 313 на поверхности, 194 проекции и 14 мест вариантов.** Добавление других моделей не означает, что вся микрогеометрия этих образований завершена.

OpenEar и другие открытые источники исследованы для дальнейшего развития. История сравнения моделей — `research/head-model-review.json`, подробный реестр поиска и ограничений — `research/skull-detailed-sources.json`. Источники, лицензии и изменения опубликованных дополнительных моделей также сохранены в `site/skull-z-detail.json` и `site/skull-microct.json`.

У девяти карточек мышц нет отдельной геометрии в выбранном наборе: передняя, верхняя и задняя ушные мышцы с двух сторон; мышца, опускающая бровь, с двух сторон; поперечная мышца подбородка. Носовая и круговая мышца рта не разделены в исходной геометрии на части TA98. Глубокая часть и ресничный пучок круговой мышцы глаза доступны как карточки. Неустановленные функция и конкретное кровоснабжение поперечной мышцы подбородка явно помечены.

Русские названия сверены с книгой Колесникова (2003). Сведения о мышцах имеют ссылки в карточках; расхождения источников сохранены в примечаниях. Реестр фактов и источников: `research/head-evidence.json`. IFAA и русское издание одного стандарта подтверждают номенклатуру и **не выдаются за два независимых анатомических учебника**.

Для трёх костных терминов сохранена печатная редакция TA98: `A02.1.03.031` — `septum sinuum frontalium`; `A02.1.05.017` — перегородка клиновидных пазух; `A02.1.05.018` — апертура клиновидной пазухи. Электронная IFAA содержит более позднюю форму первого термина и обратную нумерацию двух последних. Скрипт проверяет эти различия редакций отдельно, затем показывает ровно три прежних расхождения по костям ноги. В мышцах сохранены исходные `m. levator labii superioris alaeque nasi` и код `A04.1.03.012` для `m. depressor septi nasi`.

## Сборка и проверка головы

Готовые модели уже входят в `site/`; для запуска скачивать STL не нужно. Для изменения карточек и повторной проверки:

```powershell
py -3 scripts/make_head_data.py
py -3 scripts/make_pins_head.py
py -3 scripts/export_head_evidence.py
py -3 verify/verify_ta98.py
py -3 verify/verify_head.py
py -3 verify/verify_head_positions.py
py -3 scripts/make_local.py site/index.html site/local.html
```

Для проверки интерфейса: `npm --prefix tools ci`, затем из `tools/` выполнить `npx playwright install chromium`; из корня — `node tools/verify-atlas.mjs`. Проверяются 390 и 1280 px, светлая и тёмная темы, карточки, части, поиск, тест, загрузка руки и ноги. Скриншоты и отчёт сохраняются в `shots/head/`. При нестандартном расположении Chromium задайте полный путь в переменной `ATLAS_CHROMIUM`.

Для повторной сборки геометрии используется `scripts/manifest_head.py`: `py -3 scripts/fetch_stl.py manifest_head stl_head`, затем тот же `build_glb.py` и gltfpack, что описаны в AGENTS.md. Кости головы сохранены без упрощения; обе стороны взяты из отдельных исходных STL. Исходные координаты заданы в `build_head/landmarks_ta.js` и `pins_head/ta.json`. Уточнения и новые выборки — `build_head/landmarks_{face,cranial,temporal}_extra.js` и `pins_head/{face,cranial,temporal}-extra.json`; `scripts/head_localization.py` объединяет их по кости и коду TA98, сохраняя тип локализации и пояснение к модели. Описания и ссылки находятся в `scripts/head_{face,cranial,temporal}_evidence.py`. После пересборки обязательна визуальная проверка каждой кости.

`verify/verify_head_positions.py` проверяет, что опорная точка действительно лежит на назначенной ей сетке с допуском 0,3 мм; результат — `verify/head-position-geometry.json`. Такая проверка обнаруживает смещение и ошибку системы координат, но не подтверждает анатомическое название и не превращает проекцию в видимый рельеф.

Дополнительная модель Z-Anatomy собирается скриптами `scripts/inspect_z_detail.py` и `scripts/package_z_detail.py`; для первого нужен локальный исходный `Startup.blend` и `bpy`. Он открывается с отключённым исполнением встроенных скриптов. `scripts/build_skull_microct.py` читает исходную бинарную сегментацию Halle, проверяет её контрольную сумму, извлекает и упрощает поверхность. Исходные архивы и промежуточные файлы находятся в `research/cache/` и не публикуются. Готовые GLB и описания уже входят в `site/`.

## Публикация

`main` содержит исходники, `gh-pages` — готовую папку сайта. `py -3 scripts/package_site.py dist` создаёт полноценный `dist/index.html` из фрагмента, копирует данные и модели, добавляет `.nojekyll`. На GitHub Pages публикуется содержимое `dist/`. `scripts/sync_github.py` — резервная публикация через Git Data API при недоступности обычного Git; она использует уже настроенный системный менеджер учётных данных и не сохраняет токены в проекте.

## Структура

```
site/            готовый сайт (index.html — фрагмент страницы для Claude Artifact, local.html — полная страница)
  data.js        мышцы, группы, кости руки (тексты карточек)
  data-leg.js    то же для таза и ноги
  data-head.js   карточки головы (генерируются из head_muscles.py и head_terms.py)
  pins.js        точки на костях руки (генерируется скриптом)
  pins-leg.js    точки на костях таза и ноги (генерируется скриптом)
  pins-head.js   полный каталог черепа и маркеры с типами локализации (генерируется)
  skull-detail.html отдельный просмотр Z-Anatomy и микро-КТ со срезом
  skull-z-detail.glb, skull-z-detail.json учебная геометрия костей и пазух, источники и лицензия
  skull-microct.glb, skull-microct.json поверхность отдельного препарата, обработка и ограничения
  bodymap.js     карта областей для фигуры на стартовом экране
  *-glb.txt      3D-модели (GLB в base64; -q- — запасной вариант без сжатия meshopt)
  body-*.webp    слои фигуры стартового экрана
scripts/         конвейер сборки (Python): модели, точки, стартовая фигура, проверки
build/, build_leg/   инструмент расстановки точек (pintool.html + landmarks*.js) для руки и ноги
pins/, pins_leg/     вычисленные координаты точек (JSON) — источник для pins*.js
build_head/          pintool и воспроизводимые выборки маркеров черепа
pins_head/           исходные и уточнённые координаты, типы локализации и ограничения
research/head-*.json реестры анатомических источников, проверки разметки и открытых моделей
verify/          эталонный список TA98 с сайта IFAA и скрипт сверки
bp/              таблица «название структуры → id файла BodyParts3D»
body/, skeleton_parts.json   сборка фигуры стартового экрана
tools/package.json           three@0.170.0 и gltfpack для сборки
```

Технические детали, команды и правила для правок — в **AGENTS.md**.
