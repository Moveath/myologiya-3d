### Порядок восстановления

Для каждого ID пройди применимые методы: локальные исходники → научная модель с правами → выделение по подтверждённым границам → сегментация лицензированных КТ/МРТ → контролируемое отражение проверенной стороны → параметрическая реконструкция по пространственным данным. Это варианты, не обязательные последовательные повторы. Перечитай уже выполненные попытки; повторять их можно только при новом источнике, границе, позе или методе.

Сразу реши, нужно ли создавать отдельный меш. Части непрерывной мышцы могут требовать маски; группа/общий сосуд может требовать связи с существующими владельцами; скрытая внутренняя структура может вообще отсутствовать в наружной сетке. Для каждого решения сохрани объяснение и источники.

Проверяй сторону, единицы, оси, вид, форму, положение, анатомические соседи, начала/прикрепления, идентичность сегмента и варианты. Для нового факта — минимум два независимых подтверждения. Регистрация по bbox/ICP, отсутствие столкновений и близость к поверхности не доказывают анатомию. Масштаб нельзя подгонять ради исчезновения пересечений. Не переносить координаты пинов между образцами автоматически.

Новые производные создавай отдельно. Не изменяй оригинальные OBJ/GLB/base64 и принятые координаты. Не децимируй кости. Зеркалирование допускается только с проверенной средней плоскостью, исправлением winding/нормалей и проверкой соседства; происхождение отмечай как зеркальную учебную реконструкцию. Не зеркаль непарные и индивидуальные варианты как обязательные структуры. Не заменяй работающих соседей только для интеграции проблемного кандидата.

Для тонких мышц/пучков/сосудов сохраняй параметры, опорные области, направления, радиусы/толщины и степень уверенности. Если пространственных данных не хватает, создай воспроизводимый технический прототип только в тестовой сборке и перечисли недостающие данные. ### Допуск и интеграция

Различай четыре результата: (1) исследовательский кандидат; (2) технически исправная тестовая модель; (3) учебный допуск с ограничениями; (4) полная анатомическая приёмка. Не требуй от учебной модели недостижимой микроточности, но не принимай неизвестную идентичность/сторону, грубую неправильную топографию, отсутствие доказательств основных прикреплений или несовместимые права.

Подключай производные к существующим карточкам только после индивидуального учебного допуска.
