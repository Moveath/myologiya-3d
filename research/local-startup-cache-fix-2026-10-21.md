# Локальный атлас: восстановление выбора разделов

21.10.2026 · LOG-20261021-06 · SYS-LOCAL-ASSET-CACHE.

Во встроенном браузере воспроизведён экран пользователя: изображение скелета есть, список разделов и подписи отсутствуют. Консоль сообщает `SyntaxError: The requested module './atlas-controls.js' does not provide an export named 'framingBasis'`. Чистый Playwright загружал актуальный модуль без ошибки; встроенный браузер использовал прежний модуль по неизменившемуся URL. Свежий HTML ожидал новый экспорт, поэтому выполнение останавливалось раньше `renderHome()`. Предыдущая проверка в чистом профиле не выявляла этот сценарий.

Исправления:

- `scripts/make_local.py` добавляет версии по SHA-256 содержимого к локальным JS-адресам и скриптам данных. Import map также версионирует вложенные проектные модули, например visibility → model-sides. Одинаковые сборки дают одинаковые адреса. Версии Three.js/BVH и их vendor-файлы не менялись.
- `site/atlas-runtime.js` отслеживает ошибки запуска и необработанные отказы до готовности приложения. Ошибка отсутствующего экспорта теперь показывает сообщение вместо молча пустого меню. После запуска временные обработчики снимаются; прежняя обработка WebGL/contextlost сохранена.
- `site/index.html` включает эту проверку; `site/local.html` пересобран. Геометрия, координаты и анатомические карточки не редактировались.

Первый запуск Python-фикстур не получил доступ к временному каталогу sandbox. Фикстуры перенесены в временную папку внутри `verify/`, проверка пройдена; это ограничение тестового окружения, не ошибка атласа. Браузерные прогоны ограничены 45 секундами, отдельные ожидания 6–15 секундами; финальная страница после проверки отказа восстановлена без перехватов. Проверка на 390 px — эмуляция, не физический телефон.

Дальнейшая локальная работа: после изменения исходного HTML или JS/данных пересоздавать `site/local.html` штатной командой `python scripts/make_local.py site/index.html site/local.html`, затем обновлять вкладку. Перезапуск статического сервера не нужен. Автоматический live reload не добавлялся. Публикация в интернет не выполнялась.
