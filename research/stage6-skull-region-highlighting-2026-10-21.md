# Этап 6 — пилот выделения областей черепа

LOG-20261021-02. Реализован общий механизм выбора размеченной геометрии. **В основной атлас допущен один проекционный контур. Две частичные поверхности отростков подготовлены как черновики и отключены при окончательной приёмке.** Полные основания отростков, суставные поверхности, борозды и швы не объявлены размеченными. Остаток **20 noModel** не изменён; новые модели не восстанавливались.

## Что видно пользователю

- «Цвета костей» сохраняет существующую палитру соседних костей; выбранная кость получила более заметный светлый акцент.
- «Область ориентира» независимо включает выделение выбранного пина/карточки. Смена ориентира заменяет выделение, закрытие пина снимает его. Можно скрыть выделение, сохранив выбор, изоляцию и ракурс.
- Карточка сообщает **что именно размечено**. «Ракурс разметки» показывает участок с подходящего направления. Для остальных карточек явно написано, что область не размечена; прежние пины и ограничения сохранены.
- Маски следуют видимости владельца, стороне, прозрачности и срезу. Общая карточка сохраняет участвующие кости; отсутствие маски не заменяется окраской всей кости под видом области.

## Получение и хранение разметки

Три исходные кости имеют по одному замкнутому мешу и одному материалу, без отдельного материала отростка/суставной поверхности. Экспортированы точные массивы **опубликованных** `head-glb.txt` и `head-q-glb.txt`, а не другая сборка.

Для отверстия выделены исходные силуэтные рёбра при нижнем направлении наблюдения; из графа оставлен основной замкнутый цикл просвета. После осмотра исключены мелкие циклы рельефа. Итог — 62 ребра, степень каждой вершины 2, все рёбра принадлежат источнику. Контур проверен снизу и косо в Blender. Это граница видимого просвета указанной проекции, не все верхние/нижние края.

Для отростков выделены связные дистальные участки ниже `y=1.501 m` **только этого образца**. Ограничение выбрано консервативно, чтобы исключить неразмеченный переход основания; оно не является научно установленной границей частей. Включённые исходные грани проверены снаружи и изнутри отдельно справа/слева. Такая маска не выведена из расстояния до пина, но её верхний предел всё же технический. Поэтому окончательная приёмка отклонила её включение в обычный атлас: статус `draft_partial_surface`, runtime запрещает её отображение даже при выборе пина. Положительный UI-тест черновика не является анатомическим допуском.

Списки с разграничением допущенного контура и отключённых черновиков: `scripts/skull_region_annotations.json`. Генератор `scripts/make_skull_region_masks.py` проверяет SHA исходных файлов и создаёт `site/skull-region-masks.json`. Для q-варианта построено точное взаимно-однозначное соответствие вершин/треугольников: **0 отклонения мировых координат**, без интерполяции. Face ID между вариантами не предполагаются одинаковыми.

## Реализация и масштабирование

`site/atlas-regions.js`: source SHA + geometry SHA + primitive + исходные face/edge IDs. Неизвестный хеш → отказ от маски с обычным пином, без отказа загрузки кости. Проверка требует Web Crypto (HTTPS или localhost). На клик не выполняются поиск границ, BVH-перестроение или сегментация.

Выделение — отдельный объект только для выбранной записи: один дополнительный draw call для 62 отрезков допущенного контура. Поверхностный renderer испытан отдельно на тестовых 278/275 гранях, но эти черновики не включаются в продукте. Исходные вершины/индексы не редактируются; overlay не участвует в raycast/occlusion. Глобальные clipping planes действуют на него как на основной меш. Прозрачность наследуется от владельца. Несколько записей манифеста могут связываться с одним pin ID на разных костях; неполный комплект масок не показывается как полный.

Для следующей кости нужны проверенная аннотация того же источника, стабильный pin ID, точный scope, обе загрузочные версии и тесты. Интерфейс переписывать для каждой структуры не требуется. Объёмное заполнение каналов и произвольное автоматическое выделение не реализованы.
